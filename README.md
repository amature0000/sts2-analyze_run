# sts2-analyze_run
[![GitHub downloads](https://img.shields.io/github/downloads/amature0000/sts2-analyze_run/total.svg?logo=github)](https://github.com/amature0000/sts2-analyze_run/releases)


A simple Slay the Spire 2 mod for analyze run data.

## Features
- Export run data
- Analyze&display run data

## Installation
1. go to releases page and download `.zip` file
2. Extract the downloaded `.zip` file.
3. Move the extracted folder to your desired location
